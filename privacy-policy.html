Privacy Policy

Effective Aug 16, 2026 Applies to AI Clipping Pipeline Contact afferedo720@gmail.com
In short: This pipeline stores platform access tokens locally, one file per connected account, only to publish clips on the account owner's behalf. It never sees platform passwords, never sells or shares data with third parties, and access can be revoked at any time from the platform's own settings.
01

Who this covers

AI Clipping Pipeline is operated by a single individual to publish short-form video clips to TikTok, Instagram, and YouTube accounts that have been explicitly connected to it. This policy describes what data the pipeline handles for those connected accounts - it is not a general-audience consumer app.

02

What is collected

DataSourcePurpose
OAuth access and refresh tokensPlatform's own consent screenPublish clips to the connected account
Account / page identifiersPlatform APIAddress the right destination account

Publish status and basic analyticsPlatform API responsesConfirm a post succeeded; inform future clip selection

Platform passwords are never collected, seen, or stored - sign-in happens entirely on the platform's own OAuth page.

03

How it's stored

Access tokens are stored locally as one file per connected account, kept outside of source control, and used only by the pipeline process itself to make authenticated calls to that platform's official API. There is no central server collecting tokens across accounts or operators.

04

How it's used

  • To authenticate a single publish request to the platform the token belongs to.
  • To check whether a previously submitted post finished publishing.
  • To refresh an expiring token so the account owner isn't asked to re-authorize constantly.

Data is never used for advertising, resold, or shared with any third party beyond the destination platform's own API required to publish the content.

05

Retention and deletion

A token is kept only as long as the account stays connected. Deleting the local token file, or revoking access from the platform's own app-permissions page, immediately and permanently ends the pipeline's ability to act on that account. Email afferedo720@gmail.com to request confirmation that an account's data has been removed.

06

Your controls

Every connected account owner can revoke this pipeline's access at any time from that platform's own settings (e.g. TikTok's or Instagram's connected-apps page) - no request to the operator is required, and revocation takes effect immediately on the platform's side.

07

Children's privacy

This pipeline is a creator/operator tool, not directed at children, and is not knowingly used to connect accounts belonging to children.

08

Changes to this policy

This policy may be updated as the pipeline's data handling changes. The effective date above reflects the last revision.

09
